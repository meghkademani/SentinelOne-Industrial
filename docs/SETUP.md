## 10. Project Structure

The repository contains the following main project files and directories:

```text
SentinelOne-Industrial/
│
├── archive/
├── docs/
├── models/
├── sketch_aug13a/
├── src/
│
├── .gitignore
├── README.md
├── requirements.txt
├── safety_log.csv
├── yolo11n.pt
│
├── sentinelone_analytics.py
├── sentinelone_industrial_final.py
├── sentinelone_main_yolo_zone_stage3.py
├── sentinelone_serial.py
├── sentinelone_stage5.py
├── worker_detection.py
└── worker_detection_yolo.py
```

### Main application

`sentinelone_main_yolo_zone_stage3.py`

The primary entry point used to start the SentinelOne Industrial monitoring system.

### Industrial safety application

`sentinelone_industrial_final.py`

Contains the industrial worker-safety monitoring implementation.

### Serial communication

`sentinelone_serial.py`

Handles serial communication between the Python application and the Arduino.

### Analytics

`sentinelone_analytics.py`

Contains analytics and visualization functionality used by the project.

### Worker detection

`worker_detection.py`

Contains worker-detection functionality used by the project.

### YOLO worker detection

`worker_detection_yolo.py`

Contains YOLO-based worker-detection functionality.

### Additional processing

`sentinelone_stage5.py`

Contains additional monitoring and processing logic developed during the project's development stages.

### Dependencies

`requirements.txt`

Contains the Python packages required to run the project.

### YOLO model

`yolo11n.pt`

The YOLO model used by the worker-detection system. The model is currently located in the repository root.

### Safety log

`safety_log.csv`

Contains safety-related log and event data generated by the monitoring system.

### Documentation

`docs/`

Contains project documentation, including this setup guide.

### Repository directories

The `archive/`, `models/`, `src/`, and `sketch_aug13a/` directories are currently reserved for project organization and future development. They may be empty in the current version of the repository.
