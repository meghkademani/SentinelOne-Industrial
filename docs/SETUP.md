## 10. Project Structure

The current project is organized into the following main files and directories:

```text
SentinelOne-Industrial/
│
├── archive/
├── docs/
├── models/
├── sketch_aug13a/
├── src/
│
├── .gitignore
├── README.md
├── requirements.txt
├── safety_log.csv
├── yolo11n.pt
│
├── sentinelone_analytics.py
├── sentinelone_industrial_final.py
├── sentinelone_main_yolo_zone_stage3.py
├── sentinelone_serial.py
├── sentinelone_stage5.py
├── worker_detection.py
└── worker_detection_yolo.py
```

### Main application

`sentinelone_main_yolo_zone_stage3.py`

Main entry point for the SentinelOne Industrial monitoring system.

### Industrial safety application

`sentinelone_industrial_final.py`

Contains the main industrial safety monitoring implementation.

### Serial communication

`sentinelone_serial.py`

Handles communication between the Python application and the Arduino.

### Analytics

`sentinelone_analytics.py`

Contains analytics-related functionality used by the project.

### Worker detection

`worker_detection.py`

Contains worker-detection functionality used by the project.

### YOLO worker detection

`worker_detection_yolo.py`

Contains YOLO-based worker detection functionality.

### Additional processing

`sentinelone_stage5.py`

Contains additional processing logic used during the project's development stages.

### Dependencies

`requirements.txt`

Contains the Python packages required to run the project.

### YOLO model

`yolo11n.pt`

The YOLO model file used by the worker-detection system. The model is currently located in the repository root.

### Safety log

`safety_log.csv`

Stores safety-related log or event data generated by the project.

### Documentation

`docs/`

Contains project documentation and setup instructions.

### Source code

`src/`

Contains supporting source-code components used by the project.

### Archive

`archive/`

Contains archived project files and previous development versions.

### Development files

`sketch_aug13a/`

Contains the Arduino sketch and related hardware-development files.
